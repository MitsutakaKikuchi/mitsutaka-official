## ① 概要

長唄をはじめとする三味線演奏家の、**国際的な活動を見据えた公式ウェブサイト**を制作する。
「伝統」と「モダン」を両立させ、海外の主催者・メディア・ファンが直感的に活動内容を把握し、出演依頼に至れる導線を持つサイトを目指す。

- **対象ユーザー**: 国内外の公演主催者／メディア関係者／一般ファン
- **言語**: 日本語・英語の2言語（i18n 設計で将来の言語追加に対応）
- **必須コンテンツ**: プロフィール/経歴、公演スケジュール、問い合わせ/出演依頼
- **デバイス**: スマートフォン・タブレット・PC（モバイルファーストのレスポンシブ）

## ② デザインコンセプトの言語化

### 2-1. 全体の世界観：「静と動」「余白の美」

日本美術の**間（ま）と余白**を活かしたミニマルな構成を基調とし、演奏写真・動画で**動的なエネルギー**を対比的に見せる。
「和風サイト＝赤・金・筆文字でゴテゴテ」という古い表現は避け、**洗練された無彩色ベース＋一点豪華主義**で国際的な現代美術館のような上質さを狙う。

| 要素 | 方向性 |
|------|--------|
| 第一印象 | 静謐・上質・凛とした緊張感 |
| 避けるもの | 過度な装飾、和柄の多用、観光土産的な「ザ・和風」 |
| 参考イメージ | 現代美術館・国際的アーティストのポートフォリオ・高級ブランドのブランドサイト |

### 2-2. カラーパレット

無彩色を主役にし、三味線・和の世界観を**一色のアクセント**で象徴する。

| 役割 | 色 | 用途 |
|------|----|------|
| ベース（背景） | 生成り／墨白 `#F7F5F0` 〜 純白 | 余白・基調 |
| メインテキスト | 墨黒 `#1A1A1A` | 本文・見出し |
| アクセント | 朱 `#B7282E` または 藍 `#1B3A5B` のいずれか1色 | CTAボタン・リンク・強調 |
| 補助 | 淡灰 `#8A8580` | キャプション・罫線 |

> 朱＝津軽三味線の力強さ／藍＝古典・端正さ。アーティストの芸風に合わせてどちらか1系統に統一する。

### 2-3. タイポグラフィ

国際サイトでは**和文・欧文の混植バランス**が品質を決める。

- **見出し（日本語）**: 明朝系（例: Noto Serif JP / 游明朝）で凛とした印象。または上質なゴシック（Noto Sans JP）でモダンに。
- **見出し（欧文）**: 上品なセリフ体（Playfair Display / Cormorant）またはモダンサンセリフ（Inter / Manrope）。
- **本文**: 可読性重視で Noto Sans JP / Inter。
- **アーティスト名のロゴタイプ**: 専用のレタリングまたは縦組みで象徴的に扱う（縦書きは `writing-mode: vertical-rl` を部分的に使用）。

### 2-4. レイアウト・UI 原則

- **モバイルファースト**: 最小幅 320px から設計、ブレークポイントは 640 / 768 / 1024 / 1280px を基準。
- **余白を大胆に**: コンテンツ密度を下げ、1スクリーン1メッセージ。
- **縦書きの部分活用**: 見出しやキャッチコピーに縦組みを混ぜ、和の個性とモダンさを両立。
- **グリッド**: 公演一覧・ギャラリーはレスポンシブグリッド（CSS Grid）。
- **ナビゲーション**: PCは上部固定ヘッダー、スマホはハンバーガー＋全画面オーバーレイ。言語切替（JP/EN）を常時表示。

### 2-5. モーション・インタラクション

「動」を担う演出。ただし過剰にせず上品に。

- ファーストビューで演奏動画またはヒーロー写真をフルスクリーン表示（自動再生・ミュート・ループ）。
- スクロール連動のフェードイン／パララックス（控えめに）。
- 三味線の「撥（ばち）音」をイメージした、ホバー時の繊細なマイクロインタラクション。
- `prefers-reduced-motion` を尊重し、モーション無効設定にも対応（アクセシビリティ）。

## ③ サイト構成（情報設計）

```
TOP（ヒーロー：動画/写真 + キャッチコピー）
├─ About（プロフィール/経歴）
│   ├─ アーティスト紹介・芸歴
│   ├─ 受賞歴・主な実績
│   └─ プレス向け資料（高解像度写真・プロフィール文DL）
├─ Schedule（公演スケジュール）
│   ├─ 今後の公演（日付・会場・国・チケットリンク）
│   └─ 過去の公演アーカイブ
├─ Media（任意 / 推奨）
│   ├─ 動画（YouTube埋め込み）
│   └─ 写真ギャラリー
├─ Contact（問い合わせ/出演依頼）
│   ├─ 一般問い合わせフォーム
│   └─ 出演・ブッキング依頼フォーム（用途別）
└─ 共通: 言語切替 / SNSリンク / フッター
```

> Media（動画/音源）は今回の必須選択外だが、演奏家サイトでは説得力に直結するため**強く推奨**。最低限 TOP または About に演奏動画を1本埋め込むことを提案する。

### 主要導線（CTA）
全ページから **「出演依頼（Booking）」** へ到達できることを最優先。ヘッダーCTAボタンとして常時設置。

## ④ 技術構成（モダンフレームワーク）

### 4-1. 推奨スタック

| レイヤー | 推奨 | 理由 |
|----------|------|------|
| フレームワーク | **Astro**（第一推奨） / Next.js | コンテンツ主体の静的サイトに最適。JS最小で高速・SEO強。国際化も容易 |
| UIライブラリ | React or Svelte（必要箇所のみ） | Astro の Islands で動的部分のみ実装し軽量化 |
| スタイリング | **Tailwind CSS** | レスポンシブ・デザインシステム構築が高速。一貫性を担保 |
| 多言語(i18n) | Astro i18n / `next-intl` | URLルーティング（`/ja/` `/en/`）で言語分割、SEO対応 |
| アニメーション | Framer Motion / GSAP（控えめに） | 上質なモーション演出 |
| ホスティング | **Vercel** または **Cloudflare Pages** | 自動デプロイ・CDN・高速・無料枠あり |
| フォーム | Formspree / Resend + サーバーレス関数 | バックエンド不要で問い合わせ受信 |
| コンテンツ管理 | Markdown / MDX または Headless CMS（microCMS等） | 公演情報をコード知識なしで更新したい場合は Headless CMS |

> **選定の考え方**: 更新頻度が高い「公演スケジュール」を本人が更新するなら **microCMS等のHeadless CMS** を、開発者が随時更新するなら **Markdown/MDX** を採用。

### 4-2. パフォーマンス・SEO 要件

- **Core Web Vitals** 良好（LCP < 2.5s）。ヒーロー動画は軽量化・遅延読込。
- 画像は **WebP/AVIF**、`next/image` 相当の最適化・遅延読込。
- **構造化データ（JSON-LD）**: `Person`（アーティスト）、`Event`（公演）、`MusicGroup` を実装し検索結果を強化。
- **OGP / Twitter Card**: SNS共有時に演奏写真が映えるよう設定。
- **hreflang** タグで日英ページの関係を明示（国際SEO）。
- サイトマップ・`robots.txt` 自動生成。

### 4-3. アクセシビリティ（国際標準）

- **WCAG 2.1 AA** 準拠を目標。
- 十分なコントラスト比、キーボード操作、altテキスト、`prefers-reduced-motion` 対応。
- 動画は字幕（日英）対応を推奨。

### 4-4. 解析・運用

- アクセス解析: Google Analytics 4 または Plausible（プライバシー配慮）。
- Cookie 同意バナー（EU/GDPR対応、海外アクセスを想定するなら必須）。

## ⑤ 必要な写真・映像素材の指示

国際サイトでは**ビジュアルの質がブランド価値を決定する**。プロカメラマンによる撮影を強く推奨。

### 5-1. ヒーロー素材（最重要）
- **演奏中の動画**（横位置・フルHD以上、16:9）: 1〜3分。BGM/演奏音入り。Web用に短縮ループ版も用意。
- **ヒーロー用写真**（横位置・高解像度・余白多め）: 文字を重ねる前提で被写体を片側に寄せた構図を数枚。

### 5-2. ポートレート / プロフィール用
- 正面・斜めの上半身ポートレート（明るい背景／暗い背景の2パターン）。
- 三味線を構えた全身カット。
- プレス配布用の**高解像度（300dpi / 長辺3000px以上）**版を別途用意。

### 5-3. 演奏・パフォーマンス
- ステージでの演奏シーン（手元のアップ＝撥さばき、表情、全景の引き）。
- 撥・三味線そのもののディテール写真（質感・伝統美を伝える静物カット）。

### 5-4. 撮影トーン指示
- **自然光またはシネマティックな陰影**で、無彩色基調のサイトに馴染む落ち着いたトーン。
- 過度なレタッチ・派手な背景を避け、被写体と「間」を活かす。
- 縦位置・横位置の**両方**を撮影（SNS・モバイル用に縦素材も必要）。
- すべて**Web使用許諾を得たもの**（クレジット表記要否を確認）。

### 5-5. 補助素材
- ロゴ / アーティスト名のレタリング（ベクター: SVG）。
- ファビコン用のシンボルマーク。
- 公演フライヤー等のアーカイブ画像（過去実績用）。

### 必要素材サマリー

| 種類 | 用途 | 形式・要件 |
|------|------|-----------|
| 演奏動画 | TOPヒーロー | 16:9, FHD+, ミュート可ループ版 |
| ヒーロー写真 | TOP背景 | 横位置, 余白構図, 高解像度 |
| ポートレート | About / プレス | 正面・斜め, 縦横両方, 300dpi版 |
| 演奏シーン | Media / About | 手元・表情・引きの複数カット |
| 静物（撥・三味線） | アクセント | ディテール強調 |
| ロゴ/シンボル | 共通 | SVGベクター |

## ⑥ 制作フェーズ（進行の目安）

1. **設計**: ワイヤーフレーム（日英・モバイル/PC）→ デザインカンプ作成・合意
2. **素材準備**: 撮影・原稿（日英プロフィール文、公演データ）整備
3. **実装**: フレームワーク構築 → 共通コンポーネント → 各ページ → i18n → フォーム
4. **検証**: レスポンシブ／パフォーマンス／アクセシビリティ／SEO／英語表記校正
5. **公開・運用**: 独自ドメイン設定、解析導入、更新フロー（CMS）の引き継ぎ
